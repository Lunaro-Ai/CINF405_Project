
## Project code name: BlackWall

## About The Project

Video Game Tracker is a website where users can keep track of video games they are currently playing, have completed, or want to play. Users will be able to write reviews, take notes while playing, and create their own achievements or challenges for individual games.

The goal of this project is to give people who play video games a place to organize their games and keep a record of their experiences. The website will also include a tree system that connects a game to other similar games, allowing users to explore more games through different branches.

## Planned Features

- **Game tracking:** Keep a list of games you are playing, have completed, or want to play.
- **Reviews:** Write reviews for games you have played.
- **Notes:** Save notes for individual games while playing.
- **Custom achievements:** Create personal challenges for games.
- **Game tree:** Explore similar games through a branching tree of connected games.
- **User accounts:** Save and manage your own game collection.
